# Project Rules & Design Preferences

- **Default Accent Blue**: Use `#4080E7` as the primary/default blue accent color across the app UI (highlights, buttons, badges, active indicators, and section highlights).
- **Default Section Title Design**: Use `typography.h2` (`fontSize: 16`, `fontWeight: '600'`, `#FFFFFF`, `letterSpacing: 0.4`) as the default design for all section titles and sub-section headers across the app for visual consistency.
- **Default Primary Button Text Style**: Use uppercase text with `fontSize: 14`, `fontWeight: '600'`, `letterSpacing: 1.2` (matching `PrimaryButton` / quest buttons) for all action buttons across the app for visual consistency.
